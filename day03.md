# Day 3 - Installing Jupyter Notebook

Jupyter Notebook - this is where you actually write and run Python code in the browser, cell by cell.

Install: `conda install notebook`
Run: `jupyter notebook` (opens in the browser)

Things I noted:
- Code cells run with Shift+Enter
- You can mix code with notes using markdown cells
- Restart the kernel when things get stuck - happens more than you'd think
