# Day 5 - Thinking in Terms of Data

This one was more concept than tool. The main point: in ML everything is data, and you have to start thinking in rows and columns.

- Each row = one observation (e.g. one customer)
- Each column = one feature (e.g. age, purchase amount)
- The thing you want to predict = the label

Also, data types matter - numbers and categories need different handling. And the big lesson: your model is only as good as your data. Garbage in, garbage out.
