# Day 1 - Installing Anaconda

Started AI/ML today. First thing was installing Anaconda.

Anaconda is basically Python plus a bunch of data science libraries packed together, so you don't have to install everything one by one. It also comes with conda, which manages packages and environments.

Steps I followed:
1. Downloaded the installer from anaconda.com (Windows, 64-bit)
2. Ran it, kept everything default
3. Opened Anaconda Prompt and ran `conda --version` to check it worked

That's it for day 1. Simple start.
