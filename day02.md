# Day 2 - Conda Prompt

Today was about the conda prompt. It's just a terminal, but set up for conda commands.

Main commands I learned:
- `conda --version` — check install
- `conda create -n myenv python=3.10` — new environment
- `conda activate myenv` / `conda deactivate` — switch in and out
- `conda install numpy pandas` — install packages
- `conda list` — see what's installed
- `conda env list` — see all environments

The big idea: separate environments for separate projects so packages don't clash with each other. Makes sense.
